# Sheets

This folder contains **problem sheets**: curated lists of problems grouped by **topic**, each one meant to be solved from start to finish to build solid intuition on a specific technique.

Every sheet lives in its own folder, and each solution file is prefixed by the **problem letter**.

Legend used in the tables below:

| Symbol | Meaning |
|:------:|---------|
| ✅ | Solved |
| ⬜ | Not solved yet |
